# YVR Heart Signal

밴쿠버 미팅을 위한 작은 진행 도구. Google Forms 응답 CSV 한 장으로 **취향 시그널**과 **Two Truths and a Lie**를 진행합니다.

## 실행

Node.js와 패키지 설치 없이 Python 3만으로 실행할 수 있습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 <http://127.0.0.1:4173>을 여세요. Node.js가 있다면 `npm run dev`도 같은 서버를 실행합니다. 정적 웹사이트라 `dist/`를 정적 호스팅에 배포할 수도 있습니다. 저장소는 비공개로 생성했으며, 호스팅은 별도로 배포하지 않았습니다.

## 준비와 진행

1. Google Sheets에서 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)**을 선택합니다.
2. CSV를 업로드하거나 업로드 영역에 끌어다 놓습니다.
3. 진행 준비에서 닉네임, 사용할 취향 질문, 참가자별 세 문장을 확인합니다.
4. **진실과 거짓** 탭에서 문장을 한 줄에 하나씩 적고, 각 참가자의 거짓 문장 하나를 지정합니다. 이 화면에는 정답이 있으므로 진행자가 준비할 때 사용하세요.
5. 홈에서 게임을 선택합니다. 거짓 정답을 아직 지정하지 않아도 취향 시그널은 시작할 수 있습니다.

- **취향 시그널:** 질문마다 참가자 카드 순서를 섞습니다. 카드를 누르면 닉네임을 공개하고, 다시 누르면 답변으로 돌아갑니다. 공개한 상태는 이전·다음·홈 이동 후에도 유지합니다. 카드 색은 참가자와 연결되지 않습니다.
- **참가자별 Q&A:** 닉네임을 선택하면 선택에서 제외한 질문까지 포함한 모든 취향 질답과 두 가지 진실을 모아 봅니다. 거짓 문장은 표시하지 않으며, 정답이 지정되지 않은 참가자는 진실 문장을 숨깁니다.
- **Two Truths and a Lie:** 참가자별 세 문장 중 하나를 선택한 뒤 정답을 확인합니다. 진실은 초록 테두리, 거짓은 붉은 테두리와 글자로 표시합니다. 선택·정답 공개 상태는 이동 후에도 유지됩니다.
- 좌우 화살표 키로 이전·다음으로 이동할 수 있습니다.
- 상단 **Heart Signal**을 누르면 응답, 정답 설정, 게임 진행 상태를 모두 초기화하고 CSV 업로드 화면으로 돌아갑니다.
- 각 게임 마지막에는 **처음으로**와 **홈 화면** 버튼이 나옵니다. 처음으로는 해당 게임 상태를 초기화합니다.
- 설정을 수정하면 관련 게임의 진행 상태가 초기화됩니다. 문장을 편집하면 해당 참가자의 거짓 정답을 다시 선택해야 합니다.
- 빈 취향 답변은 ‘아직 답변이 없어요’로 표시합니다. 참가자가 홀수라면 마지막 줄에 카드 하나를 표시합니다. 모바일에서도 2열을 유지합니다.

## CSV 구조

| 열 | 내용 |
| --- | --- |
| 첫 번째 | Timestamp (게임에는 표시하지 않음) |
| 두 번째 | 닉네임 |
| 세 번째 ~ 마지막 바로 앞 | 취향 질문. 열 제목이 질문이며, 각 행이 답변 |
| 마지막 | Two Truths and a Lie. 셀 안의 줄바꿈으로 세 문장 분리 |

UTF-8 CSV, BOM, 쉼표와 따옴표가 포함된 답변, 여러 줄 셀, CRLF/LF 줄바꿈을 처리합니다. 제목 행을 기준으로 열 개수가 다른 행과 닉네임 없는 행은 오류를 표시합니다. 파일 크기는 10MB까지입니다. 마지막 셀의 비어 있는 줄은 무시하며, 정확히 세 문장이 되어야 진실·거짓 게임을 시작할 수 있습니다.

첨부된 실제 파일은 **23열, 참가자 4명, 취향 질문 20개**의 구조로 확인했습니다. 실제 응답과 닉네임은 소스에 넣지 않았습니다. ‘먼저 둘러보기’는 네 명의 가상 참가자 데이터입니다.

## 데이터 처리

응답 파일은 브라우저 메모리에서만 처리합니다. 서버 업로드, 분석 도구, 외부 폰트, 외부 API, 쿠키, localStorage를 사용하지 않습니다. **새로고침하거나 탭을 닫으면 응답·정답 설정·진행 상태가 사라집니다.** 행사 중에는 탭을 새로고침하지 마세요.

정답은 클라이언트 메모리에 있으므로 참가자 개인에게 보안을 제공하는 시스템은 아닙니다. 진행자 컴퓨터에서 화면을 공유하는 용도입니다. 개인 응답 CSV와 `private-data/`는 Git에서 제외합니다.
